# Requirement Analysis

## Project Title

**Streamlining IT Procurement: Automating Standard Laptop Orders**

## 1. Functional Requirements

### Employee

The employee should be able to:

* Login to the system
* Submit a laptop request
* Select a standard laptop model
* Enter required details
* Submit the request
* View request status
* View previous requests

### Manager

The manager should be able to:

* View submitted requests
* Review laptop requests
* Approve requests
* Reject requests
* Add comments

### IT Procurement Team

The procurement team should be able to:

* View approved requests
* Process laptop orders
* Update procurement status
* Maintain laptop inventory
* View procurement history

### Administrator

The administrator should be able to:

* Manage users
* Manage laptop models
* Manage standard specifications
* View all requests
* Generate reports

## 2. Non-Functional Requirements

### Performance

The system should respond quickly to user actions.

### Security

Only authorized users should access the system.

### Usability

The interface should be simple and easy to use.

### Reliability

The system should store requests accurately.

### Maintainability

The system should be easy to update and maintain.

## 3. Hardware Requirements

* Computer or laptop
* Minimum 4 GB RAM
* Internet connection
* Modern web browser

## 4. Software Requirements

* Operating System: Windows/Linux/macOS
* Frontend: HTML, CSS, JavaScript
* Backend: Python/FastAPI
* Database: SQLite/MySQL
* Browser: Google Chrome or Microsoft Edge
* Code Editor: Visual Studio Code
* Version Control: Git and GitHub

## 5. User Roles

| Role             | Main Responsibility    |
| ---------------- | ---------------------- |
| Employee         | Submit laptop request  |
| Manager          | Approve/reject request |
| Procurement Team | Process approved order |
| Administrator    | Manage system          |

## 6. Expected Outcome

The system should provide a centralized and automated process for standard laptop procurement.
