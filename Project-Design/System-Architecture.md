# System Architecture

## Project Title

**Streamlining IT Procurement: Automating Standard Laptop Orders**

## Architecture

The application follows a three-layer architecture:

### 1. Presentation Layer

The frontend provides:

* Login page
* Dashboard
* Laptop request form
* Request status page
* Admin page

### 2. Application Layer

The backend handles:

* User authentication
* Request validation
* Approval workflow
* Procurement processing
* Status updates
* Notifications

### 3. Database Layer

The database stores:

* User information
* Laptop models
* Laptop specifications
* Procurement requests
* Approval information
* Order status

## Basic Flow

Employee → Laptop Request → Validation → Manager Approval → Procurement → Order Completion
