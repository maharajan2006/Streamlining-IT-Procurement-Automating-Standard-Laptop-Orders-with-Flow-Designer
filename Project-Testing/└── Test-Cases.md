# Project Testing

## Project Title

**Streamlining IT Procurement: Automating Standard Laptop Orders**

## Test Case 1 – Login

**Input:** Valid username and password

**Expected Result:** User should successfully login.

## Test Case 2 – Invalid Login

**Input:** Incorrect username or password

**Expected Result:** Error message should be displayed.

## Test Case 3 – Laptop Request

**Input:** Valid laptop request details

**Expected Result:** Request should be submitted successfully.

## Test Case 4 – Empty Request

**Input:** Required fields left empty

**Expected Result:** Validation message should be displayed.

## Test Case 5 – Approval

**Input:** Manager approves a request

**Expected Result:** Request status should change to Approved.

## Test Case 6 – Rejection

**Input:** Manager rejects a request

**Expected Result:** Request status should change to Rejected.

## Test Case 7 – Procurement

**Input:** Approved laptop request

**Expected Result:** Procurement team should be able to process the order.

## Test Case 8 – Status Tracking

**Input:** Existing request

**Expected Result:** Employee should be able to view the current request status.

## Testing Conclusion

The system will be tested using functional test cases to ensure that the major modules work correctly and that invalid inputs are handled properly.
