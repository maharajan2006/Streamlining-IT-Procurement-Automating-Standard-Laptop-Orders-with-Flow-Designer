# Project Demonstration

## Project Title

**Streamlining IT Procurement: Automating Standard Laptop Orders**

## Demo Video Content

The project demonstration video will include:

### 1. Project Introduction

Introduce the project name and team members.

### 2. Problem Statement

Explain the difficulties in manually processing standard laptop orders.

### 3. Project Purpose

Explain how the system automates the laptop procurement process.

### 4. Login

Demonstrate the user login process.

### 5. Employee Dashboard

Show the employee dashboard and available options.

### 6. Laptop Request

Demonstrate how an employee submits a standard laptop request.

### 7. Manager Approval

Demonstrate how the manager reviews and approves or rejects the request.

### 8. Procurement

Show how the procurement team processes an approved request.

### 9. Order Tracking

Demonstrate how the request status can be tracked.

### 10. Final Output

Show the completed procurement process and final system output.

## Demo Video Requirement

The video should contain:

* Screen recording
* Student voice-over
* Project name
* Project purpose
* Project benefits
* Working process
* Final output

The completed video will be uploaded to Google Drive and the sharing permission will be set to:

**Anyone with the link – Viewer**
